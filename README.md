A make.fun entry for "Fortune in a Pot": one kind, funny fortune for a houseplant, 120 characters or fewer. The program writes the fortune — a warm prediction about the plant's keeper talking to it again tomorrow, and this time not pretending it was for the cat — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes exactly one line (99 characters, no trailing newline) to `/output/entry.txt`, then reads the file back and verifies the written bytes match the fortune exactly.
